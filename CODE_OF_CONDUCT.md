# Code of Conduct

API Circle Studio adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its Code of Conduct. The full text is published at the link above and
is incorporated here by reference.

In short:

- Everyone participating in this project — issue reporters, contributors,
  reviewers, and the maintainer — agrees to keep the project a respectful,
  welcoming space, regardless of background, identity, or experience level.
- Disagreements about technical direction are welcome and expected. Personal
  attacks, harassment, and bad-faith participation are not.
- The maintainer is responsible for clarifying standards and may take
  proportionate action when this Code is not followed, including editing
  or removing comments, closing issues or pull requests, and, for repeated
  or severe violations, banning a contributor from the project.

## Reporting

If you experience or witness behavior that violates this Code — in an
issue, a pull request, a discussion, or any other project space — please
report it privately to:

> **apicircle365@gmail.com**

Include what happened, where it happened (links help), and anyone else
who was involved or witnessed it. Reports are read by the project
maintainer only. You will receive an acknowledgement within 5 business
days. Reporters are not identified to the subject of the report without
their permission.

## Scope

This Code applies in all project spaces — the GitHub repository (issues,
pull requests, discussions, code review comments), the project's
official communication channels, and any space where someone is
representing API Circle Studio.
