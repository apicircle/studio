# MCP tool catalog reference

> **Deprecated for API Circle Studio.**
> Studio no longer ships, publishes, or configures the MCP server. The active MCP surface moved to API Circle Lens, where it is exposed through `apicircle-lens mcp` and governed by Lens entitlement rules.

This file is retained as a legacy Studio documentation stub so old links do not imply that Studio still owns MCP deployment.

For current MCP tool names, schemas, AI-client setup, and protocol validation, use the API Circle Lens documentation and the Lens CLI:

```bash
apicircle-lens mcp --repo ./your-workspace-repo
```

Existing `.apicircle` workspaces created by Studio remain compatible with Lens.
